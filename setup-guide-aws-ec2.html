🔌 Choose Your Deployment Path

📦
Path A: S3 Package (Recommended)
Pre-build locally, upload zip to S3, deploy on EC2. Faster setup — no build step on the server. No GitHub access required on the server.
Steps: 1 → 2 → 3 → 4A → 8 → 9 → 10 → 11
🐙
Path B: GitHub Clone
Clone repo directly on EC2 and build on the server. Simpler if you don't have an S3 bucket. Requires Git and ~5 min build time.
Steps: 1 → 2 → 4B → 8 → 9 → 10 → 11
1

Launch a Windows EC2 Instance

Create a new EC2 instance from the AWS Console
~5 min
SettingRecommended Value
AMIWindows Server 2022 Base
Instance Typet3.medium (2 vCPU, 4 GB RAM)
Storage50 GB gp3 SSD
Key PairSelect or create (needed for password retrieval)
Security GroupAllow RDP (3389), HTTP (80), HTTPS (443)
💡 Tip: For production with multiple users, consider t3.large (8 GB RAM). Enable an Elastic IP so the public IP persists across restarts.
2

Connect via Remote Desktop (RDP)

Retrieve the admin password and RDP into the instance
~3 min
  • In EC2 Console, select instance → Connect → RDP Client
  • Click "Get Password" → Upload your .pem key file
  • Copy the decrypted Administrator password
  • Open Remote Desktop and connect to the public IP
💡 Tip: Wait 5-10 minutes after launch for the Windows password to be available. The instance must fully initialize first.
3

Path A: Prepare & Upload Package to S3

Run on your local machine (Mac/Linux) to build and upload a deployment zip
~5 min
Build the package locally
cd ~/stakeholder360 bash deploy/package.sh # build zip only bash deploy/package.sh s3://your-bucket/youth360 # build + upload to S3
What the script does
  • Installs dependencies and builds the production bundle
  • Packages everything into a timestamped zip + youth360-latest.zip
  • Uploads both files to your S3 bucket (if URL provided)
  • Generates a 7-day pre-signed URL for the EC2 instance to download
💡 Tip: Requires aws CLI configured with S3 write access. Run aws configure first if not set up. Alternatively, upload the zip from dist/ to S3 manually via the AWS Console.
4

Path A: One-Command Setup from S3

On the EC2 instance — download the pre-built package and install
~3 min
Open PowerShell as Administrator and run:
Set-ExecutionPolicy Bypass -Scope Process -Force # Download the setup script Invoke-WebRequest -Uri "https://raw.githubusercontent.com/kellybock/stakeholder360/main/deploy/setup.ps1" -OutFile setup.ps1 # Run with your S3 URL .\setup.ps1 -S3Url "https://your-bucket.s3.amazonaws.com/youth360-latest.zip"
✅ Done! The script installs Node.js + NSSM, downloads & extracts your pre-built package, configures the firewall, and starts Youth360 as a Windows service. No Git or build step needed. Skip to Step 8.
💡 Tip: You can also use a pre-signed S3 URL (generated by the package script) so the bucket doesn't need to be public.
4

Path B: One-Command Setup from GitHub

On the EC2 instance — clone the repo and build on the server
~10 min
Open PowerShell as Administrator and run:
Set-ExecutionPolicy Bypass -Scope Process -Force # Install Git first (needed to clone) choco install git -y $env:Path = [System.Environment]::GetEnvironmentVariable("Path", "Machine") # Clone and run setup git clone https://github.com/kellybock/stakeholder360.git C:\youth360 cd C:\youth360 .\deploy\setup.ps1
✅ Done! The script installs Chocolatey, Node.js, NSSM, builds the app, configures the firewall, and starts Youth360 as a Windows service. Skip to Step 8.
5

Manual Setup — Install Dependencies

If you prefer manual control instead of the automated scripts above
~5 min
Install Chocolatey
Set-ExecutionPolicy Bypass -Scope Process -Force [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.SecurityProtocolType]::Tls12 Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
Install Node.js 20, Git (if using GitHub), and NSSM
choco install nodejs-lts nssm -y # S3 path (no Git needed) choco install nodejs-lts git nssm -y # GitHub path
Refresh PATH and verify
$env:Path = [System.Environment]::GetEnvironmentVariable("Path", "Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path", "User") node --version # v20.x.x
6

Manual — Get the Application

Download from S3 or clone from GitHub
~3-5 min
Option A: Download from S3
Invoke-WebRequest -Uri "https://your-bucket.s3.amazonaws.com/youth360-latest.zip" -OutFile $env:TEMP\youth360.zip Expand-Archive -Path $env:TEMP\youth360.zip -DestinationPath C:\
Option B: Clone from GitHub + build
git clone https://github.com/kellybock/stakeholder360.git C:\youth360 cd C:\youth360 npm install --omit=dev npm run build
7

Manual — Environment, Firewall & Service

Configure secrets, open ports, and register as a Windows service
~3 min
Create environment file
notepad C:\youth360\apps\web\.env.local
Paste these variables
SESSION_SECRET=<64-char hex string> NRIC_ENCRYPTION_KEY=<32-char hex string> ANTHROPIC_API_KEY=sk-ant-api03-your-key-here
Open firewall ports
New-NetFirewallRule -DisplayName "Youth360-HTTP" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow New-NetFirewallRule -DisplayName "Youth360-HTTPS" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow New-NetFirewallRule -DisplayName "Youth360-App" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow
Install as Windows service
nssm install youth360 C:\youth360\apps\web\node_modules\.bin\next.cmd start nssm set youth360 AppDirectory C:\youth360\apps\web nssm set youth360 AppEnvironmentExtra "NODE_ENV=production" "PORT=3000" nssm set youth360 Start SERVICE_AUTO_START nssm start youth360
✅ Check: Open a browser on the server and visit http://localhost:3000 — you should see the login page.
8

Set Up IIS Reverse Proxy (Optional)

Route port 80/443 traffic through IIS to Node.js on port 3000
~5 min
Run the IIS setup script
.\deploy\ssl-setup.ps1 # HTTP only with self-signed cert .\deploy\ssl-setup.ps1 -Domain yourdomain.com # With Let's Encrypt SSL
💡 Tip: Without IIS, users can access the app directly on port 3000. IIS adds SSL termination and lets you serve on standard ports 80/443.

11

Redeploy Updates

When you have a new version, redeploy with one command
~2 min
From S3 (re-package locally first, then on EC2):
# On your Mac — rebuild and upload new package bash deploy/package.sh s3://your-bucket/youth360 # On EC2 — download and restart (preserves .env.local) .\deploy\redeploy.ps1 -S3Url "https://your-bucket.s3.amazonaws.com/youth360-latest.zip"
From GitHub:
cd C:\youth360 .\deploy\redeploy.ps1
💡 Tip: The S3 redeploy automatically backs up and restores your .env.local so your API keys and secrets are preserved. The GitHub redeploy pulls latest, rebuilds, and restarts the service.

🎉 You're Live!

Your Youth360 portal is now running on a Windows Server EC2 instance and accessible to your team.
