Launch a Windows EC2 Instance

Create a new EC2 instance from the AWS Console
~5 min
SettingRecommended Value
AMIWindows Server 2022 Base
Instance Typet3.medium (2 vCPU, 4 GB RAM)
Storage50 GB gp3 SSD
Key PairSelect or create (needed for password retrieval)
Security GroupAllow RDP (3389), HTTP (80), HTTPS (443)
💡 Tip: For production with multiple users, consider t3.large (8 GB RAM). Enable an Elastic IP so the public IP persists across restarts.
2

Connect via Remote Desktop (RDP)

Retrieve the admin password and RDP into the instance
~3 min
  • In EC2 Console, select instance → Connect → RDP Client
  • Click "Get Password" → Upload your .pem key file
  • Copy the decrypted Administrator password
  • Open Remote Desktop and connect to the public IP
💡 Tip: Wait 5-10 minutes after launch for the Windows password to be available. The instance must fully initialize first.
3

Option A: One-Command Setup (Recommended)

Run the automated setup script to install everything
~10 min
Open PowerShell as Administrator and run:
Set-ExecutionPolicy Bypass -Scope Process -Force git clone https://github.com/kellybock/stakeholder360.git C:\youth360 cd C:\youth360 .\deploy\setup.ps1
✅ Done! The script installs Chocolatey, Node.js, Git, NSSM, builds the app, configures the firewall, and starts Youth360 as a Windows service. Skip to Step 9.
4

Option B: Manual — Install Dependencies

Install Chocolatey package manager, then Node.js, Git, and NSSM
~5 min
Install Chocolatey
Set-ExecutionPolicy Bypass -Scope Process -Force [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.SecurityProtocolType]::Tls12 Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
Install Node.js 20, Git, and NSSM
choco install nodejs-lts git nssm -y
Refresh PATH and verify
$env:Path = [System.Environment]::GetEnvironmentVariable("Path", "Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path", "User") node --version # v20.x.x git --version # git version 2.x
5

Manual — Clone and Build

Pull the Youth360 source code and build the production bundle
~5 min
git clone https://github.com/kellybock/stakeholder360.git C:\youth360 cd C:\youth360 npm install --omit=dev npm run build
6

Manual — Configure Environment

Create your .env.local with secrets and API keys
~3 min
Create environment file
notepad C:\youth360\apps\web\.env.local
Paste these variables
# Auth (generate random values) SESSION_SECRET=<64-char hex string> NRIC_ENCRYPTION_KEY=<32-char hex string> # AI Providers (add at least one) ANTHROPIC_API_KEY=sk-ant-api03-your-key-here OPENAI_API_KEY=sk-your-key-here GOOGLE_AI_API_KEY=your-key-here # Database (optional — uses in-memory store by default) DATABASE_URL=postgresql://user:pass@rds-endpoint:5432/youth360
⚠ Security: Never commit .env.local to Git. For production, use AWS Secrets Manager.
7

Manual — Install as Windows Service

Use NSSM to run Youth360 as an auto-starting Windows service
~2 min
# Register the service nssm install youth360 C:\youth360\apps\web\node_modules\.bin\next.cmd start nssm set youth360 AppDirectory C:\youth360\apps\web nssm set youth360 AppEnvironmentExtra "NODE_ENV=production" "PORT=3000" nssm set youth360 Start SERVICE_AUTO_START # Start it nssm start youth360
✅ Check: Open a browser on the server and visit http://localhost:3000 — you should see the login page.
8

Configure Windows Firewall

Allow inbound traffic on ports 80, 443, and 3000
~1 min
New-NetFirewallRule -DisplayName "Youth360-HTTP" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow New-NetFirewallRule -DisplayName "Youth360-HTTPS" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow New-NetFirewallRule -DisplayName "Youth360-App" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow
9

Set Up IIS Reverse Proxy (Optional)

Route port 80/443 traffic through IIS to Node.js on port 3000
~5 min
Run the IIS setup script
.\deploy\ssl-setup.ps1 # HTTP only with self-signed cert .\deploy\ssl-setup.ps1 -Domain yourdomain.com # With Let's Encrypt SSL
💡 Tip: Without IIS, users can access the app directly on port 3000. IIS adds SSL termination and lets you serve on standard ports 80/443.

Configure AI & Verify

Add your AI API keys via the admin panel and test all features
~2 min
In the portal UI
  • Go to Admin → API Keys & Settings
  • Add your Anthropic / OpenAI / Gemini API key
  • Select default model (e.g. Claude Sonnet 4.6)
  • Test AI Assistant: ask "Who are our top stakeholders?"
Verify all pages work
  • Dashboard — live KPI cards populated
  • Stakeholder Directory — 200 profiles with search
  • 360 Profile — all 9 tabs with data
  • Engagement Analytics — charts and segments
  • Network Graph — interactive force graph
  • RM Workspace — pipeline, alerts, reminders
  • AI Assistant — streaming chat with database context
12

Redeploy Updates

When new code is pushed, pull and redeploy with one command
~2 min
cd C:\youth360 .\deploy\redeploy.ps1
💡 Tip: The redeploy script pulls the latest code, reinstalls dependencies, rebuilds, and restarts the Windows service automatically.

🎉 You're Live!

Your Youth360 portal is now running on a Windows Server EC2 instance and accessible to your team.

http://<your-ec2-ip>:3000
